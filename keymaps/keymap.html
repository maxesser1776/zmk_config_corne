How to read this

A
Big label = what the key types when tapped.
SAlt
Small label = what it does when held. Tap S for "s", hold it for Alt ("homerow mods").
'hold: Nav
Colored thumb key = tap for the character, hold to switch to that layer (color = layer).
Dark key = the key your thumb is already holding to be on this layer.
▽
Dashed ▽ = not used here; the key keeps doing what it does on Base.
DCtrl ⚡
⚡ = instant modifier (CAD mode only), for one-handed shortcuts while the right hand is on the mouse.

Key colors

Modifier (Ctrl / Shift / Alt / Win)Editing (copy, undo, delete…)Cursor movementMouse controlMedia / volumeWindows: apps & windowsApp-specific shortcutSystem: reset / flash / forgetBluetooth / output select

Layers work like Shift does for capitals: hold a thumb key and the whole keyboard changes to that layer's keys. Each layer card's color matches the thumb key that opens it on Base. Combos: press two keys at the same instant for a third action (map at the bottom).
